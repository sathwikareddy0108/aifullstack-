Git commands:

=> git init	create a new Git repository in your project folder
=> git remote add origin <URL>	connects your local repository to a GitHub repository
=> git status	show the current status of your files
=> git add	stages all changes to be committed
=> git commit -m "message"	saves your changes with a message
=> git push	uploads your commits to Git hub
=> git pull	downloads the latest changes from GitHub
